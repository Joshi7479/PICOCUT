PICUT©

Welcome on my site and to my Project: PICUT!



What is PICUT©?

PICUT© is an opensource Software, to use your Raspberry Pi Pico together with buttons as a Shortcut-Board.



How does PICUT© work?

PICUT© has 3 main components: The Setup Software in Java or Python (both available), the Software on the Pi written in Python and the config.txt File.


The Setup-Tools (In Java and Python, in english or German) help you, to set your Shortcuts. The config.txt safes them and the code.py on the Pi executes them.


There are also 2 Programms for the Pi. Why? Because one is for the German QWERTZ Layout and the other one for the QWERTY-Layout.


The main script (code.py) basically tells you Pc: Oh, hey, I am an Keyboard and if you then push a button it tells the Pc, you had just wrote this on it.



How to install it?

Just follow the Steps in the Setup (available in English or German) on Github, to get it onto your Pi.

It is totally free and opensource. So give it a try!
