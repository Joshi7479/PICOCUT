# PIOCCUT
Use your Raspberry Pi Pico as an Shortcut-Board! / Nutze deinen Raspberry Pi Pico als Schortcut-Board!
Use the interactive Setup in German and English to get everything ready with an GUI!
Use the setup files in german and english to install it manually on a Raspberry Pi Pico.
For any other microcontrollers you can build your own fork based on this Project!
Want to try it first? https://wokwi.com/projects/478207020368504833
